# Changelog

## [1.0.1]

### Changed

- Seedream 5.0 lite uses `dola-seedream-5-0-lite-260128`.
- Removed `seedream-5-0-260128` and `seedream-5-0-lite-260128`.

## [1.0.0]

### Added

- BytePlus ModelArk task plugin for overseas Ark (`https://ark.ap-southeast.bytepluses.com`).
- Dreamina Seedance 2.5 / 2.0 video models with resolution and reference-video usage profiles.
- Dola Seedream 5.5 / 5.0 and Seedream 5.0 / lite image models.
- Native Ark routes under `/api/v3/...` and `/byteplus`, plus `openai_video`, `openai_image`, and `openai_responses`.
